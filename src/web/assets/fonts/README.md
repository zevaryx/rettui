# Fonts

`FiraCodeNerdFont-Regular.woff2` and `FiraCodeNerdFont-Bold.woff2` are
[Fira Code](https://github.com/tonsky/FiraCode) as patched by
[Nerd Fonts](https://github.com/ryanoasis/nerd-fonts) (release 3.x,
`FiraCode.tar.xz`), converted from TTF to WOFF2 with fontTools. They are
licensed under the SIL Open Font License 1.1: see [OFL.txt](OFL.txt).

rettui's web UI serves them itself (`/fonts/…`), so browsers never fetch fonts
from a third party.
