Identities, backups and pipes

What the web UI leaves out, because anyone with its login link controls it. This window is only on this computer.

Each identity has its own address, name, conversations and contacts. Its key is the file that makes it you: anyone who has a copy can pose as you, so keep copies private.

    Keep another identity

    Copy the identity in use

    Settings, contacts, messages and your identity in one file, to restore on another computer or after a reinstall (below, or rettui restore). Attachments are left out. Seal it with a passphrase so the file can be kept anywhere; without one, it holds your key in the clear.

    Restore a backup

    Puts the backup's settings, contacts, messages and identity in place of the ones of the identity in use. What's there now is moved aside, into a before-restore folder in the data folder, not deleted. rettui stops while it's restored and starts again, and the main window reloads.

    A pipe interface runs a program and talks to it over its input and output, to reach Reticulum through a radio or a script. It runs with your account's rights, so only add commands you trust. New ones start turned off.
